# Gmail 記帳匯入提案

只定義此來源的需求與驗收，不修改 APK。確認入帳、去重與素材隱私遵循[共用流程提案](https://github.com/RichardHan/ji-zhang/pull/1)。

## 範圍

先支援使用者選取或分享的郵件，不要求讀取整個信箱。三類郵件共用同一入口，但處理規則不同：

- **帳單**：擷取期間、應繳金額、到期日；應繳不等於已付款。
- **發票**：從郵件或附件擷取發票號碼、商家、日期、金額；付款未確認時只留候選。
- **信用卡消費通知**：擷取商家、金額、幣別與時間，區分消費、取消、退款；月結帳單不重算既有明細。

直接同步 Gmail 需另行評估 OAuth 權限與 Google 驗證，本提案不假設已取得授權。

## 驗收

各用一封帳單、發票與刷卡通知驗收。未付帳單不算支出；同一消費同時有發票與刷卡通知時提示疑似重複。
