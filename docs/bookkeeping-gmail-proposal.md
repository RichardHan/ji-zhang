# Gmail 郵件匯入

從「記一筆」選「匯入 Gmail 郵件」，開啟一封 .eml 或 UTF-8 純文字檔，也可以貼上主旨與內文。在 Android 可透過分享選單傳入純文字或 .eml 郵件。App 只讀取所選內容；可從郵件中挑選 PDF、圖片或文字發票附件。原始郵件與附件不會送往 AI 或寫入試算表。

- 帳單顯示計費期間、應繳金額及到期日。月結帳單只供核對，明細不會再次列支。
- 發票提供號碼、商家、日期及金額供修改。加入待確認清單後，請核對實際付款再按「已付款，確認入帳」。
- 信用卡通知區分消費、退款、取消與交易未成立。外幣通知保留原幣金額供核對，請依入帳資料補填 TWD 金額。取消或未成立的交易不新增收支。

相同日期、商家、TWD 金額與收支類型的發票和刷卡通知會提示疑似重複，可保留其中一筆。郵件來源與試算表沿用既有的分帳與確認流程，沒有新增 Gmail OAuth 權限。
