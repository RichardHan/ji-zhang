# Android 停留記帳建議

在「記一筆 → 停留記帳建議」開啟前景定位並允許精確位置。保持頁面開啟，App 會用最近的位置與移動摘要辨識一次停留。停留滿約 15 分鐘、關閉定位、離開頁面或 App 進入背景時，本次定位即結束。下次使用需要重新開啟。

## 查詢附近場所

「停留後自動查詢附近場所」預設關閉。若使用者勾選，或在停留結束後按「查詢附近場所」，App 才將停留點附近的小範圍傳給 OpenStreetMap。場所篩選在裝置上完成。帳本只收到使用者確認的交易欄位。

- 曾移動後停在停車場或路邊收費區附近，列出可能的停車地點與本次停留時間。已知免費停車場不列入。
- 在台北時間早餐（06–10 時）、午餐（11–14 時）或晚餐（17–21 時）時段，附近餐飲場所可列為候選。店名與餐飲類型取自地圖標記。位置不準、訊號中斷或持續通過時不累計停留。停在主要車道上，或剛快速移動後缺乏步行線索時，不推測用餐。
- 同一次停留的停車與用餐選項一起顯示，起初均未勾選。可各選一項、略過整次停留，或於待確認清單修正備註、類別與實付金額。補齊並確認才寫入試算表。

GPS 與地圖只能提示可能的支出；是否付費、在哪家用餐及實際金額均由使用者確認。共用流程見 [PR #1](https://github.com/RichardHan/ji-zhang/pull/1)。
