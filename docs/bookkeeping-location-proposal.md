# 停車與用餐地點推測提案

只定義此來源的需求與驗收，不修改 APK。確認入帳、去重與素材隱私遵循[共用流程提案](https://github.com/RichardHan/ji-zhang/pull/1)。

## 範圍

使用者主動開啟後，App 才用停留地點、時間和附近場所產生兩種記帳建議：

- **停車**：有先移動、後停在停車場或路邊收費區附近的跡象時，提示「可能有停車費」，列出可能的停車地點與停留時間。不能確定有收費，金額留白。
- **用餐**：在早餐、午餐或晚餐時段於同一地點停留，且附近有餐飲場所時，建議可能的店家或餐飲類型（例如「午餐可能吃了麵」）。候選不止一個時讓使用者選擇；無法判斷時不猜特定店家或菜色。

建議不是交易。使用者可以修正店家、餐點或類別、補上實付金額後確認入帳，也可以略過。功能預設關閉；只保留產生建議所需的資料，不保留完整定位軌跡。若查詢場所需要把位置傳給第三方，先告知並由使用者選擇。

## 驗收

1. 移動後停在停車場附近，最多出現一次停車費建議，不填入預估費用；略過不入帳。
2. 午餐時間在餐飲場所附近定點停留，顯示可能店家或餐飲類型；訊號不足時不做具體推測。僅路過或塞車不觸發用餐建議。
3. 同一停留若同時符合兩種情境，一次提示即可提供兩種選項，不替使用者選，也不自動入帳。
4. 關閉定位後不再蒐集停留資料，手動記帳仍可使用。
