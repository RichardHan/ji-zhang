# 電子發票與收據匯入

在「記一筆」開啟「匯入電子發票／收據」。可選擇 UTF-8 TXT、PDF 或圖片，拍攝台灣電子發票的左側 QR Code，或從 Android 其他 App 分享純文字到「記帳」。一次處理一張發票；所有辨識都在裝置上完成。

核對發票號碼、商家（備註）、日期及 TWD 金額，再加入待確認清單。一般收據可留空發票號碼。左側 QR Code 含開立日期和含稅總額；商家名稱須從收據文字取得或手動補填。[財政部電子發票證明聯條碼規格](https://www.einvoice.nat.gov.tw/static/ptl/ein_upload/download/20.pdf)

同一本帳內會依發票字軌號碼與雙月期別提示已待確認或已入帳。跨裝置送出同一發票時，試算表以相同批次憑證防止重複寫入。無發票號碼的收據沿用日期、金額與商家的相似項目提示。按下確認才會寫入交易；原始文件、QR 內容及分享文字只用於當次匯入。
